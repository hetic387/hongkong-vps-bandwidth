## 端口标称和实际能跑多少，是两个数字

结论先说：香港本地可以接近跑满端口，跨境到大陆单线程大致落在 400–600Mbps 区间，移动方向的上行会被 QoS 压到 40Mbps 以下。这不是 GoMami 独有的问题，但有具体的数字才好判断够不够用。

2025 年 12 月一份第三方测评对 HKG.Turin.Mini（2Gbps 端口）做过完整测速：

- 香港本地 Speedtest：**1986.94 / 1658.32 Mbps**，延迟 1.59ms
- Speedtest.net 节点：1988.96 / 1879.80 Mbps，1.02ms
- 新加坡：360.74 / 613.21 Mbps，35.86ms
- iperf3 到深圳电信：**475 Mbps**
- iperf3 到济南联通：**545–572 Mbps**
- iperf3 到广东移动：上行 **37.5 Mbps**，下行单次 549 Mbps
- iperf3 到宁波移动：上行 37.7 Mbps，下行 653 Mbps

另一份 2025 年 10 月的测试记录里，同一档 Turin 的香港本地跑到 1910.52 / 1778.07 Mbps。而 1Gbps 端口的 HKG.Pulse.Mini，香港本地实测 956.94 / 698.27 Mbps。

把这些数字放在一起看就清楚了：2Gbps 端口在香港本地确实摸到了接近 2Gbps，说明端口不是虚标。但你要访问的是大陆用户，单个 TCP 连接能拿到的带宽受限于跨境链路和本地出口。深圳电信 475Mbps、济南联通 545Mbps 这类结果，已经跑满了测试方本地 500Mbps 的宽带，所以更准确的说法是"受测方本地带宽成了瓶颈"，而不是"这台机器只能跑 500M"。

真正需要注意的是移动方向。多份独立测评都记录到同一个现象：移动上行被严重 QoS，下行基本正常。有测评的原话是"测了很多次上行表现都很一般，但是拿去拉 US/JP 都是正常的，下行还不错"。如果你要做的是直播推流、大文件上传、或者任何以"从服务器往大陆推"为主的业务，移动用户这条路会很别扭。

## 常见问题

**香港大带宽 VPS 的 2Gbps 端口，大陆用户能用满吗？**

单线程用不满，多线程有机会。第三方实测中，深圳电信单线程 475Mbps、济南联通 545Mbps，这两个数字已经接近测试方本地 500Mbps 宽带的上限。香港本地可以跑到接近 2Gbps。所以"能不能用满"更多取决于你的用户在哪、用什么宽带、开几个连接。

**1Gbps 和 2Gbps 端口，日常用起来差别大吗？**

对单个网站访问者来说差别不大，因为单线程跨境速度本来就到不了 1Gbps。差别体现在并发场景：多用户同时下载、CDN 回源、批量分发时，2Gbps 端口的余量更充足。如果只是建个站跑 API，1Gbps 完全够。

**流量用完了会怎样？**

可以自助买流量包补充，不用升级套餐。100GB 起售 $6，但只在当前计费周期有效。官方 FAQ 有"达到上限会怎样"的问题条目，公开页面未给出答案，建议购买前问客服确认。

**移动宽带的用户适合吗？**

需要看用途。移动方向的上行被 QoS 得比较明显，多份测评测到的上行都在 40Mbps 以下；下行正常，单次能到 500–900Mbps。如果你的业务是"用户从服务器下载"，没问题；如果是"往服务器上传"，移动这条路会很卡。

**支持 Windows 吗？**

Turin 的 Pro/Ultra 和 Pulse 的 Pro/Ultra 标注 Windows-ready，官方提供 Windows Server 2019/2022 模板。是否包含授权费用，官方页面没有说明。
